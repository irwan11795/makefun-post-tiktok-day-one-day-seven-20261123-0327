A short TikTok about the same tiny agent-built game on the day it was made and
after a week of daily updates: **ASTRO HOP**, a one-button moon hopper built by
my AI agent from a single prompt.

Day one the game is a bare grey astronaut hopping grey craters — score counter
only, nothing else. Day seven, same map and same start, it is visibly alive:
a starry sky, parallax moon mountains, coins, particle bursts, a hop trail, a
combo counter and speed lines. The video cuts between identical moments a week
apart, keeps the camera still so the change is the whole story, and closes on
the newer build being played with a line inviting viewers to start theirs at
make.fun. It ends with make.fun's referral end card carrying my referral code.

`VIDEO.json` names the video's full address on TikTok; `main.ts` (Node 22,
standard library only) copies it to the output directory for the gate. Score
is the video's views plus 10 times its likes, comments, shares and saves.
